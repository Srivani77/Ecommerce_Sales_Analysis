# Ecommerce Sales Analysis

## Project Overview
This project focuses on analyzing an E-commerce Superstore dataset using Python to understand sales performance, customer behavior, product performance, and business trends.

## Dataset
- Dataset: Sample Superstore
- Records: 9,994
- Columns: 21

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data Loading
2. Data Exploration
3. Data Cleaning and Preparation
4. Exploratory Data Analysis (EDA)
5. Category and Sub-category Analysis
6. Regional and State-wise Analysis
7. Monthly and Yearly Sales Trends
8. Customer Analysis
9. Shipping Mode Analysis
10. Discount Analysis
11. Product Performance Analysis
12. Quantity Analysis
13. Correlation Analysis
14. Business Insights and Recommendations

## Key Objectives
- Understand overall sales and profit performance.
- Identify top-performing product categories.
- Analyze customer purchasing patterns.
- Understand regional sales performance.
- Explore the relationship between discounts and profit.
- Identify business trends through visualizations.
